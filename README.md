# 🏡 Plataforma de Bienes Raíces — Next.js App

Aplicación web para explorar propiedades mediante geolocalización, galerías dinámicas y diseño responsivo.

🔗 **Demo:** [Ver plataforma](https://bieness.netlify.app/)

---

## 🛠️ Stack Tecnológico

* **Core:** Next.js 16 (App Router), React, TypeScript
* **Mapa:** React-Leaflet & Leaflet.js
* **UI:** Tailwind CSS, Swiper.js, Framer Motion

---

## ✨ Funcionalidades

* **Mapa interactivo:** Visualización de propiedades con marcadores personalizados (React-Leaflet).
* **Galerías:** Carruseles de imágenes por inmueble (Swiper.js).
* **Interacciones:** Transiciones fluidas con Framer Motion y diseño totalmente responsivo.

---

## 🚀 Instalación rápida

```bash
git clone https://github.com
cd tu-repo-bienes-raices
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.
